# EasySanskrit-AutoHotkey

[English](README.md) | [Deutsch](README_de.md)

Version 1.0.0

AutoHotkey v2を利用して、サンスクリット語のローマ字表記を簡便に入力するためのスクリプトです。

## 動作環境

- Windows
- AutoHotkey v2

## 使用方法

1. AutoHotkey v2をインストールします。
2. `EasySanskrit.ahk`をダウンロードします。
3. `EasySanskrit.ahk`をダブルクリックして実行します。

## 基本的な入力規則

| 入力 | 出力 |
|---|---|
| `a=` | ā |
| `i=` | ī |
| `u=` | ū |
| `r.` | ṛ |
| `r.=` | ṝ |
| `s.` | ṣ |
| `m.` | ṃ |
| `h.` | ḥ |
| `n^` | ṅ |
| `n~` | ñ |

## 変換の一時停止と再開

`Ctrl + Alt + F12`を押すと、すべての変換を一時停止できます。もう一度押すと再開します。
