# EasySanskrit-AutoHotkey

Version 1.0.1

[English](README.md) | [日本語](README_ja.md)

Ein einfaches AutoHotkey-v2-Skript zur Eingabe von romanisiertem Sanskrit

## Anforderungen

- Windows
- [AutoHotkey v2](https://www.autohotkey.com/)

## Installation

1. Installieren Sie AutoHotkey v2.
2. Laden Sie `EasySanskrit.ahk` herunter.
3. Starten Sie das Skript durch Doppelklick auf `EasySanskrit.ahk`.

## Grundlegende Eingaberegeln

| Eingabe | Ausgabe |
| ------- | ------- |
| `a=`    | ā       |
| `i=`    | ī       |
| `u=`    | ū       |
| `r.`    | ṛ       |
| `r.=`   | ṝ       |
| `s.`    | ṣ       |
| `m.`    | ṃ       |
| `h.`    | ḥ       |
| `n^`    | ṅ       |
| `n~`    | ñ       |

## Umwandlung pausieren und fortsetzen

Drücken Sie `Ctrl + Alt + F12`, um alle Umwandlungen zu pausieren oder wieder zu aktivieren.

## Tastaturlayouts

EasySanskrit wurde mit den folgenden Windows-Tastaturlayouts getestet:

- Japanisch
- Englisch (US)
- Deutsch

Die Eingaberegeln sind bei allen getesteten Tastaturlayouts gleich. Die Positionen der Tasten sowie die Tastenkombinationen für Zeichen wie `~`, `^`, `|` und `=` können jedoch je nach Tastaturlayout unterschiedlich sein.
